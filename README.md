# Портфолио Анны Богатырёвой

Статичный сайт: обычные HTML/CSS/JS без фреймворков и базы данных.
Хостится на любом обычном хостинге. Страницы собираются из двух файлов с текстами.

## Что где лежит

```
index.html            ← главная (генерируется, руками не правим)
cases/*.html          ← страницы кейсов (генерируются)
data/site.js          ← общие тексты: контакты, услуги, «обо мне», статистика, процесс
data/cases.js         ← КЕЙСЫ: один объект = один кейс
data/placeholders.js  ← заглушки-обложки (исчезают, когда добавишь картинку)
build.js              ← сборщик: из data/*.js делает index.html и cases/*.html
assets/css/style.css  ← весь дизайн
assets/js/main.js     ← анимации, фильтр кейсов, курсор
assets/fonts/         ← шрифты Onest и JetBrains Mono (свободная лицензия OFL), лежат на самом сайте
assets/img/           ← сюда класть свои картинки
```

## Открыть и редактировать в VS Code

1. Распакуй архив, в VS Code: **File → Open Folder** → папка `anna-portfolio`.
2. Поставь расширение **Live Server**. ПКМ по `index.html` → *Open with Live Server*: сайт откроется в браузере и обновляется при сохранении.
3. Установи **Node.js** с nodejs.org (нужен только для сборки, пакеты ставить не надо).

## Как вносить изменения

**Правка текстов или добавление кейса**

1. Открой `data/cases.js` или `data/site.js`, поменяй текст.
2. В терминале VS Code (`Ctrl+\``) выполни: `node build.js`
3. Сборщик пересоздаст `index.html` и `cases/*.html` и напишет, что ещё осталось заполнить.
4. Залей изменённые файлы на хостинг.

**Новый кейс:** скопируй любой объект в `cases.js`, поменяй `id` (латиницей, без пробелов), тексты, добавь картинки, `node build.js`. Кейс сам появится на главной, получит свою страницу `cases/<id>.html`, попадёт в `sitemap.xml` и в «следующий кейс».

**Скрыть недоделанный кейс:** `hidden: true`.

**Картинки.** Положи файлы в `assets/img/` (лучше WebP, до ~300 КБ каждая), впиши путь в `cover` (обложка) или в четвёртый элемент строки галереи, например `"assets/img/kinesiolab-1.webp"`. Для превью в соцсетях добавь `assets/img/og.jpg` размером 1200×630.

**Фото в «Обо мне»:** `about.photo` в `data/site.js`, например `"assets/img/anna.webp"` (пропорции 4:5).

**Цены в услугах:** поля `price` и `term` в `data/site.js`.

**Цвета и типографика:** переменные в начале `assets/css/style.css` (`--acid`, `--signal` и т. д.).

Не правь `index.html` и `cases/*.html` руками: следующая сборка их перезапишет.

## Перед запуском (чек-лист)

- [ ] В `data/site.js` указан `siteUrl` (адрес сайта).
- [ ] Заменены все красные `[заглушки]`, их число покажет `node build.js`.
- [ ] Добавлено фото, картинки кейсов и `og.jpg`.
- [ ] Проверено на телефоне и в разных браузерах.
- [ ] Подключена Яндекс.Метрика (`metrikaId` в `data/site.js`), если нужна статистика.

## Публикация на российском хостинге

Подойдёт любой хостинг со статикой: Timeweb, Beget, reg.ru и т. п.

1. Купи домен (`.ru` или `.рф`), удобнее у того же провайдера, что и хостинг. Нужны паспортные данные.
2. В панели хостинга привяжи домен к сайту и включи бесплатный SSL (Let's Encrypt), чтобы адрес начинался с `https://`.
3. Подключись по FTP (FileZilla, Cyberduck) или через файловый менеджер панели и залей в папку сайта (`public_html` или `www`): `index.html`, `cases/`, `assets/`, `sitemap.xml`, `robots.txt`.
4. Откройся по домену. Если DNS ещё не обновился, подожди от пары часов до суток.
5. Добавь сайт в Яндекс.Вебмастер и укажи `sitemap.xml`, чтобы поиск быстрее его нашёл.

Заливать нужно только готовые файлы: `build.js`, `data/` и `package.json` на хостинге не нужны (можно загрузить, ничего не сломается).

## GitHub: нужен ли

Для публикации не обязателен: сайт заливается по FTP. Заведи репозиторий, если хочешь историю версий и возможность откатить правку: `git init`, коммит, пуш в приватный репозиторий. Хостинг при этом остаётся обычным, файлы заливаются как раньше.
